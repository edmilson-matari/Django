# 2. Wiki — CS50 Web Programming

A Wikipedia-like online encyclopedia built with Django as part of Project 1 of Harvard University's CS50 Web Programming with Python and JavaScript course.

The application allows users to browse encyclopedia entries, search for topics, create new pages, and edit existing content. Each entry is written in Markdown and converted into HTML before being displayed in the browser.

## Features

- **Entry Pages:** View encyclopedia entries through dedicated URLs.
- **Index Page:** Browse all available encyclopedia entries.
- **Search:** Search for entries by title or find entries containing a search query.
- **Create New Pages:** Create encyclopedia entries using Markdown.
- **Edit Pages:** Modify existing entries using a pre-populated text area.
- **Random Page:** Navigate to a randomly selected encyclopedia entry.
- **Markdown Conversion:** Convert Markdown content into HTML for display.

## Technologies Used

- **Python** — Application logic.
- **Django** — Web framework and URL routing.
- **HTML5** — Page structure and forms.
- **CSS3** — Styling.
- **Markdown2** — Markdown-to-HTML conversion.
